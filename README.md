A simple python script, written for linux that helps you to (rhymes with yeat) on exams. 
Everything is running locally, using Ollama & python. Will add the functionality to work with Llama.cpp-vulkan as well.
Too bored to write a requirements.txt for this because this is a small program.

You need to have dbus and pydbus to use this, and you need a graphical environment, because this uses notifications
to send the answer to the user.

Run the program, and then use ctrl+c to copy the MCQ Question, then Ctrl+Alt+C to start the generation process
