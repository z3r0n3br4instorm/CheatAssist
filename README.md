# UniAssist

A Linux-based study tool that uses AI to help you better understand course materials
and complex concepts. Built with Ollama and RAG (Retrieval-Augmented Generation) technology.

## Features

- Load your own study materials into a knowledge database
- Select text and get AI-powered explanations based on your materials
- Works entirely locally for privacy and offline use
- Uses RAG technology to provide context-aware explanations

## Usage

1. Add your study materials to the `RAG_DATA/data.pdf` file
2. Run the program with `python main.py`
3. Select text you want to understand better
4. Press Ctrl+Alt+E to get an explanation

## Requirements

- Python 3.8+
- Ollama
- Linux with desktop notifications
- Required Python packages: pyperclip, keyboard, chromadb, ollama, pypdf, pynput

## Ethical Use

This tool is designed as a study aid to help understand course materials.
Please use responsibly and in accordance with your institution's academic integrity policies.
